=== Slim Snippets changelog ===

Every release, newest first. `readme.txt` lists only the current release.

= 1.3.0 | 2026-11-26 =
* Added a setting to delete all snippets and tags when the plugin is deleted.

= 1.2.8 | 2026-11-25 =
* Updated the readme and changelog to be more concise.

= 1.2.7 | 2026-11-25 =
* Removed the Description column from the Tags screen and the Description field from the Add New Tag and Edit Tag forms.

= 1.2.6 | 2026-11-25 =
* Added a view that shows which tag the snippet list is filtered by.
* Fixed tag counts showing 0 on the Tags screen.

= 1.2.5 | 2026-11-25 =
* Fixed a fatal error on multisite when a snippet redeclared a function or class from a Code Snippets network snippet.
* Fixed the import page linking to the wrong Plugins screen when Code Snippets is network-activated.

= 1.2.4 | 2026-11-25 =
* Fixed an active snippet that declares a function or class becoming inactive when it is saved again.
* Fixed the migration skipping an active Code Snippets snippet that has an inactive duplicate.
* Fixed the migration deactivating the Code Snippets plugin when none of the selected snippets could be migrated.
* Fixed the migration error being scrolled out of view.
* Fixed a select-all checkbox showing on a migration table with nothing to select.

= 1.2.3 | 2026-11-25 =
* Added checkboxes to the migration page, which now lists snippets in Active, Inactive and Trash tables.
* Added a "view snippet" link for each Code Snippets snippet that is not migrated.
* Updated the import and migration results to show each count on its own line.
* Updated the migration page to explain how to switch back to Code Snippets.
* Updated the migration of CSS and JavaScript snippets for Code Snippets Pro and the free plugin.
* Updated the import page to offer only Inactive while the Code Snippets plugin is active.
* Fixed a fatal error when a snippet redeclared a function or class from a Code Snippets front-end snippet.

= 1.2.2 | 2026-11-25 =
* Updated the plugin description to mention migrating from the Code Snippets plugin.
* Updated the Safe mode description.
* Fixed snippets published outside the Snippets screen becoming active without the activation checks.
* Removed snippets from Tools > Export.

= 1.2.1 | 2026-11-25 =
* Updated `readme.txt` and `README.md` for clarity and consistency.
* Updated the changelog format and added release dates.

= 1.2.0 | 2026-11-25 =
* Added updates from GitHub releases.

= 1.1.1 | 2026-11-24 =
* Added a note to the Import / Export page about importing while the Code Snippets plugin is active.
* Updated the import notes to name each file that is not valid.
* Updated the safe mode notice to say how to turn safe mode off.
* Updated the wording on the Import / Export page and the migration screens.
* Moved older changelog entries from `readme.txt` to `changelog.txt`.
* Fixed "Snippet not found." not being translatable.

= 1.1.0 | 2026-11-24 =
* Added support for `DISALLOW_UNFILTERED_HTML`.
* Updated the migration to activate an inactive copy already in Slim Snippets instead of skipping it.
* Updated the migration to copy duplicate Code Snippets snippets once.
* Updated the migration to keep the time with neither plugin running as short as possible.
* Updated the migration notice and section to show only to users who can activate plugins.
* Fixed an issue where a visitor could switch off a snippet by making it throw an error.
* Fixed an issue where a search term with "$" or "\" did not find tags as typed.
* Fixed a fatal error when a migrated copy redeclared a function or class.
* Fixed a database error when the Code Snippets table is missing.

= 1.0.9 | 2026-11-24 =
* Added migration from Code Snippets on the same site.

= 1.0.8 | 2026-11-24 =
* Updated the Export section of the Import / Export page to list each way to export.

= 1.0.7 | 2026-11-24 =
* Added a "Snippets" link on the Plugins screen.
* Updated the Import / Export page with a larger drop zone and a standard browse button.
* Updated the import notes on the Import / Export page to a bulleted list.
* Updated the Extended view of the snippets list to show "No description" for a snippet without one.

= 1.0.6 | 2026-11-24 =
* Updated the Description box on the snippet screen to be taller.

= 1.0.5 | 2026-11-24 =
* Updated the save message to mention the status only when it changed.
* Updated the priority hint to "Lower runs sooner."

= 1.0.4 | 2026-11-24 =
* Added import options for the status of imported snippets.
* Updated the import notices to name each snippet that was skipped or not activated.
* Updated the Snippets menu to list Import / Export before Tags.
* Fixed a fatal error when activating a snippet that redeclares a function or class.

= 1.0.3 | 2026-11-24 =
* Updated the Snippet box so it can no longer be hidden in Screen Options.
* Updated the Snippet box to have the same padding as the other boxes.
* Updated the activate button to say "Save & Run Once" for the run-once scope.
* Removed the Slug box from the snippet screen.

= 1.0.2 | 2026-11-24 =
* Added conversion of Code Snippets descriptions from HTML to plain text on import.
* Fixed the edit screen escaping the code and description twice.
* Fixed text such as "option_<key>" being deleted from descriptions.
* Fixed an issue where restoring a revision brought back filtered text.

= 1.0.1 | 2026-11-24 =
* Updated the import so imported snippets are always inactive.
